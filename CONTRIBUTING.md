# Contributing to TinyTots ASD Screening

Thank you for your interest in contributing to TinyTots ASD Screening!

## Code of Conduct
Please ensure all discussions and contributions remain respectful, collaborative, and focused on clinical and software excellence.

## Development Workflow
1. Fork or branch from `main`.
2. Make modular, focused changes.
3. Verify backend tests:
   ```bash
   pytest backend/
   ```
4. Verify frontend build:
   ```bash
   cd tiny-tots-assess-main
   npm run build
   ```
5. Submit a descriptive Pull Request.
